# Accessibility pass (required before you report done)

These are console-style UIs, but the site must stay fully usable by everyone.

1. **Automated audit**: inject axe-core in Playwright ONLY (do not ship it):
   `await page.addScriptTag({ url: 'https://cdn.jsdelivr.net/npm/axe-core@4.10.2/axe.min.js' })`
   then `await page.evaluate(() => axe.run())`. Run it in every major state (home,
   each section, article open, overlay open, mobile). Fix all serious/critical
   violations and record the results (before/after counts) in NOTES.md.
2. **Real DOM is the source of truth**: every piece of content and every control
   that's drawn in canvas/WebGL must exist as semantic, focusable DOM (links,
   buttons, headings, lists), in a sensible reading order. Canvas gets
   `aria-hidden="true"` or a role="img" label. Find-in-page should work where
   possible.
3. **Landmarks & headings**: `<main>`, `<nav>`, a single h1 per view, and
   a logical heading hierarchy. The page `<title>` updates per section/article.
4. **Focus**: always-visible, high-contrast focus ring (it can be themed in era
   style, but it must stay obvious). Modals/overlays/readers use `<dialog>` or
   an equivalent: trap focus, Esc closes, and focus returns to the opener.
   Spatial (arrow) navigation and Tab order must agree on which item is focused.
   Add a "Skip to content" link.
5. **Screen readers**: announce section/item changes made by arrow keys or
   gamepad via a polite `aria-live` region (debounced). Toasts use
   role="status". Decorative icons are `aria-hidden`. Custom widgets use the
   correct roles (tablist/tab/tabpanel, listbox/option, menu…) and states
   (`aria-selected`, `aria-current`, `aria-expanded`).
6. **Contrast**: body text at least WCAG AA 4.5:1 against its ACTUAL background
   (glass/blur/gradient included; check the worst case), and UI text at least 3:1.
7. **Motion**: `prefers-reduced-motion` gets a calm version (no camera sway,
   parallax, wobble, ripple or flicker; crossfades instead). Add an in-UI
   motion toggle. Nothing flashes more than 3 times per second.
8. **Sound**: muted by default, a toggle that's reachable by keyboard and
   labeled, and nothing that is conveyed only by sound.
9. **Input**: everything works with keyboard alone, mouse alone, touch alone
   and gamepad. Touch targets are at least 44px. Zoom isn't disabled
   (no `user-scalable=no`), and the layout survives 200% text zoom.
10. **No-JS / failure**: if JS or WebGL fails, there's still a readable list of
    posts, notes and projects with working links.

Add a "## Accessibility" section to NOTES.md listing what you verified, how,
and the known remaining gaps — honestly.
